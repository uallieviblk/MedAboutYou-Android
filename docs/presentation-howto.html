Using MedAboutYou

From install to a tracked daily routine — in 8 steps

Getting around

  • Three tabs: Today · Calendar · Schedules.
  • ⋮ (top-right) → Insights and Settings.
  • Search opens from Schedules → Add medicine.
  • First launch: allow notifications for reminders.

1Add a medicine

  • Go to Schedules → Add medicine.
  • Choose EMA (tap Download dataset the first time) or AIFA.
  • Type a name / ingredient; tap a result to open its record.
  • On the record, tap Add to my medication schedule.

💡 Not in the database? Type its name and tap "Add '…' as a custom medicine" (great for supplements).

2Create the schedule

  • Pick Repeat every: Once / Hours / Days / Weeks / Months / Years.
  • Add one or more dose times (e.g. 08:00, 20:00).
  • Set the allowed window, reminder cadence and optional notes.
  • Choose how it Ends: ongoing, on a date, or after N doses.
  • Check the live summary → Add to calendar.

3Track Today

  • The ring shows taken / total and your streak.
  • Tick a dose to mark it taken (stock drops by one).
  • Use Take all for a whole time block.
  • You can tick from the start of the window (e.g. 07:30 for an 08:00 dose).

4Use the Calendar

  • Days are colour-coded: green taken, blue upcoming, purple shortage, red missed.
  • Tap a day to see its agenda; tick doses there too.
  • Tap the ✎ on a row to edit a single dose.

5Edit or skip one dose

  • Change the time or window of just this dose.
  • Tick Skip this dose to drop a single occurrence.
  • Choose This dose only or This and following.
  • Tap Save. Past doses stay unchanged.

6Manage therapies

  • Each card shows the recurrence, start date and notes.
  • ⏸ pause (timed or indefinite) — ▶ resume.
  • Tap a card to edit it (changes apply from today).
  • 🗑 cancel — kept in history, never deleted.

7Watch stock & refills

  • Set stock on a medicine record, or top up by whole packs.
  • The app forecasts run-out dates automatically.
  • See them on the Today banner, the Calendar (purple days) and Insights → Next refill.

8Reminders & caregivers

  • Settings → Enable dose reminders (on by default).
  • Notifications offer Mark taken / Skip.
  • Optional: add caregiver numbers + grant SMS so an overdue dose alerts them — off by default.
  • Enable Start at boot so reminders survive a restart.

Insights & recap

  • ⋮ → Insights: adherence (7/30/90), streak, heatmap, refills.
  • Search → schedule → track → review. That's the loop.
  • Everything stays on your device.
